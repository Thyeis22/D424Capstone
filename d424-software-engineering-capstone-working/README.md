Vacation Scheduler App
Overview:

The Vacation Scheduler is an Android application that allows users to create and manage vacations and excursions. The app uses the Room database to store user-entered data and is compatible with Android 8.0 and higher.

Features:

Add, update, and delete vacations
Store vacation details (title, hotel, start date, end date)
Add, update, and delete excursions linked to a vacation
Validate date format and ensure correct date ranges
Prevent deleting a vacation with associated excursions
Set alerts for vacation and excursion dates
Share vacation details using Android sharing features

Screens:

Home screen

Vacation list

Vacation details

Excursion list

Excursion details


How to Run:

Open the project in Android Studio
Run on an emulator or Android device
Enter vacation and excursion data manually

Notes:

Data is not pre-populated; all information is entered by the user


A signed APK is included for installation
